# Android on tablets

Install [Blynx Music 1.1.0 ARM64](https://github.com/updaown-hecker/Blynx-Music/releases/download/v1.1.0/Blynx-Music-v1.1.0-arm64-v8a.apk) on an ARM64 tablet such as the Galaxy Tab S10 Lite. Blynx uses the same Android package and adjusts its layout to the current window. Wide windows use a navigation rail. The player docks alongside the library on expanded windows with enough height. Use the player’s hide and show controls to free up space. The Wide layout and Side player appearance settings are enabled by default.

The [Android 15 phone and tablet emulator checks](https://github.com/updaown-hecker/Blynx-Music/actions/runs/43764500504) tested the published universal APK. The tablet used the Galaxy Tab S10 Lite’s 1320 × 2112 screen proportions and an emulator display density. The test opened local music, rotated with audio playing, folded and reopened the side player, and checked background playback and system pause. The Galaxy Tab S10 Lite itself wasn’t tested.
