Blynx Music Android test build based on OpenTune.

- **ARM64** is the smaller download for the Samsung Galaxy S25 FE.
- **Universal** also includes the other supported processor architectures.
- The APKs use Android debug signing for sideload testing. A future build signed with a different certificate will require a fresh install.
- Check `SHA256SUMS.txt` to verify the download. The source archive attached by GitHub contains the corresponding source and GPLv3 license.

Open the downloaded APK and allow installation from the browser or file manager if Android asks. In Appearance, choose **Clear refraction**, **Original liquid**, or one of the other surface styles. Turn **Liquid Glass** off to disable optical refraction. **Reduce dynamic blur** also disables backdrop blur.
